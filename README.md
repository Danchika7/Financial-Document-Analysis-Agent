# Financial Document Analysis Agent

An AI-powered financial document analysis system that extracts, retrieves, and analyses financial information from Apple's 10-K reports using Large Language Models (LLMs).

## Features
- Financial document text extraction using PyMuPDF
- Semantic search using Sentence Transformers
- Vector similarity search using FAISS
- Retrieval-Augmented Generation (RAG)
- AI-powered question answering using Qwen2.5
- Workflow orchestration using LangGraph
- Financial metric extraction and trend analysis
- Automated PDF report generation

## Technologies Used
- Python
- PyMuPDF
- Sentence Transformers
- FAISS
- Qwen2.5
- LangGraph
- Jupyter Notebook

## Project Structure
- `Financial_Ai_Agent.ipynb` – Main project notebook
- `Apple_10K_Report_Q1.pdf` – Financial report
- `Apple_10K_Report_Q2.pdf` – Financial report
- `Apple_10K_Report_Q3.pdf` – Financial report
- `finance_dataset.zip` – Financial dataset

## How to Run
1. Download or clone this repository.
2. Open `Financial_Ai_Agent.ipynb` in Google Colab or Jupyter Notebook.
3. Install the required dependencies.
4. Upload the required financial documents and dataset.
5. Run the notebook cells sequentially.
